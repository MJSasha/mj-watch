# Сохраняемый контракт управления MJWatch TV
17.11.2026. Основание: исходники на коммите `1c66118d202238db95848a9aa98d102d27f622d2`. Дизайн меняет оформление, не команды и не переходы.

## Пульт
| Контекст | Событие | Существующий результат, который сохранить |
|---|---|---|
| Управление скрыто | ↑ | Показать управление, фокус «Назад» |
| Управление скрыто | ↓ | Показать управление, фокус Play/Pause |
| Управление скрыто | ← / → | Сразу −10 / +10 секунд; не открывать overlay |
| Управление скрыто | OK / Enter | Одно переключение play/pause и показать управление; удержание не повторяет toggle |
| Открытые кнопки | ← / → | Прежний порядок целей, disabled пропускаются; на краях нет нового wrap |
| Открытые нижние кнопки | ↑ | На шкалу при доступном seek, иначе на «Назад» |
| Верхние кнопки | ↓ | На Play/Pause при ready, иначе прежняя безопасная цель |
| Шкала | ← / → | Только кандидат позиции; начальный шаг 10 с |
| Шкала, удержание | repeatCount ≥10 / ≥20 | Шаг 30 / 60 с; границы [0, duration] |
| Шкала | OK / Enter | Один seek к кандидату, без play/pause и без второго действия на отпускание |
| Шкала | Back | Отмена кандидата; остаться в плеере, без seek |
| Шкала | ↑ | Отменить кандидат и скрыть управление; не переводить в шапку |
| Шкала | ↓ | Отменить кандидат и вернуть фокус на Play/Pause |
| Шкала | Потеря фокуса | Отменить неподтверждённый кандидат |
| Диалог | Back | Закрыть активный диалог, не выходить из плеера |
| Диалог закрыт | — | Вернуть фокус к исходной кнопке: верхние дорожки / нижние дорожки / серии / видео |
| Prompt | Появление | Фокус на основном действии; ←/→ между ним и вторичным |
| Prompt | Back / вторичное действие | Скрыть предложение, показать управление и вернуть Play/Pause |
| Обычный просмотр | Back | Выйти одним нажатием при открытом и скрытом управлении |

Примечание о Back: порядок перехвата — внешний диалог → список серий → неподтверждённый seek → prompt без статуса → выход. Новый промежуточный шаг «сначала скрыть controls, потом выйти» запрещён. Старый аудит #12 описывал другое желаемое ↑ со шкалы; приоритет у текущего проверенного поведения и требования пользователя сохранить управление.

## Таймеры и предложения
- TV скрывает управление через 6000 мс без ввода; **пауза не отменяет TV-таймер**. При modal, preview seek, status или keepVisible автоматического скрытия нет.
- Любой релевантный ввод сбрасывает таймер; аппаратные медиакнопки также учитываются.
- Prompt автоперехода появляется по допустимой метке ending или в последних 30 с. Счётчик — 10 с реально проигранного времени; пауза, модальное окно, статус и preview не расходуют отсчёт. Seek не засчитывается как просмотр.
- «Остаться» отменяет предложение до выхода из текущей финальной зоны; повторное появление после возвращения в неё сохраняется. Переход только один, с проверкой границ очереди. При auto-next=off предложение ручное, без обратного отсчёта.
- Опенинг пропускается только по валидным start/end внутри duration. Без меток не угадывать его длину.
- Автопропуск и автопереход сохраняют существующие предпочтения и правила блокировки. На последней серии нет перехода за очередь.
- Нельзя притворяться, что смена качества, дорожки, скорости или масштаба ставит видео на паузу: сохраняются фактическая позиция и playWhenReady.

## Другие источники управления
Аппаратные PLAY, PAUSE, PLAY_PAUSE, REWIND, FAST_FORWARD, NEXT, PREVIOUS остаются отдельными существующими командами, с прежними seek-интервалами Media3 и ограничениями очереди. Не подменять их предпросмотром шкалы. Повтор key-down медиакнопки не должен порождать повторный toggle.

Системные play/pause/seek, громкость и состояние внешнего Android-контроллера сохраняются. Видеодвижок, MediaSession, LAN-сессия, история и восстановление состояния не меняются ради оформления. Дизайн не вводит gestures, long-press-команды, новый пульт на телефоне или обработчик видео.
