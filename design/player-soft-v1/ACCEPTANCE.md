# Приёмка будущей реализации
Дизайн-поставка готова для обсуждения; пункты ниже ещё не являются пройденными runtime-тестами.

## Сохранение поведения
- [ ] Скрытые ↑/↓/←/→/OK соответствуют REMOTE.md; удержание OK не вызывает повторных toggle.
- [ ] На шкале есть кандидат, шаг 10/30/60 с, корректные границы; OK подтверждает один раз, Back/↓/↑/уход фокуса отменяют без seek.
- [ ] Back без modal/preview/prompt выходит одним нажатием.
- [ ] Начальный фокус и возврат из всех диалогов сохраняются; единственный видимый focus ring; фокус не уходит на фон modal.
- [ ] Верхний вход в дорожки остаётся отдельной доступной целью.
- [ ] Таймер 6 с работает также на паузе; modal/preview/status/keepVisible блокируют скрытие.
- [ ] Auto-next: 10 с проигранного времени, остановка счётчика на паузе/блокировках, отмена «Остаться», один переход, границы очереди, режим off.
- [ ] Опенинг показывается только по корректным меткам; auto-skip и отсутствие меток сохраняют поведение.
- [ ] Next/Previous недоступны на краях; один файл, пустая/неизвестная duration и unseekable не дают нерабочих целей.
- [ ] Аппаратные и системные media-команды работают; качество/скорость/масштаб/дорожки сохраняют позицию и playWhenReady.
- [ ] Recreate/возврат сохраняют существующее восстановление серии, позиции, паузы и скорости; запись истории остаётся под её настройкой.

## Визуальная приёмка
- [ ] Сопоставить T01–T09 с макетами на 1920×1080 и 1280×720 с реальной density, затем проверить на физическом TV с расстояния просмотра.
- [ ] Очень светлый/чёрный/пёстрый кадр: текст ≥4,5:1, icons и контур ≥3:1 по итоговому композиту.
- [ ] Focus отличается от selected и playing без опоры только на цвет; контур не обрезается, нет scale/glow.
- [ ] Скрытый UI оставляет только видео/субтитры. Градиент скрывается вместе с controls.
- [ ] Длинный русский заголовок/путь, большие шрифты до 200%, разные aspect ratio: без наложений/обрезки значимых действий; dialog прокручивается.
- [ ] Focus targets ≥48 dp, семантические labels актуальны; accessibility keepVisible и reduced motion сохранены.
- [ ] Модальные состояния и ошибки оформлены единообразно; фон не имеет второго контура.
- [ ] Нет нового мобильного транспорта, неизвестных языков/качеств/длительностей, миниатюр seek или несуществующего апскейлера.

## Проверки при реализации
Повторить существующие TvPlaybackStateTest, TvRemoteControlsTest и TvPlayerBehaviorTest с настоящими D-pad/OK/Back/media key events. Добавлять проверки только на новые значимые риски оформления: контур/клиппинг, крупный шрифт, состояние disabled и семантику. Снять состояния с одинаковым видео/viewport, сравнить с макетами. Не объявлять исправленными #24/#25 по визуальной проверке.
