# Приёмка телефон → ТВ

Дизайн-проект: 17.11.2026. Ниже будущие проверки реализации; сейчас они не считаются пройденными.

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| A01 | Открыть устройства | Один список телефонов, планшетов и ТВ; тип по иконке; отдельного меню ТВ нет |
| A02 | Нет добавленного ТВ | Каталог доступен; запуск/продолжение/быстрый play скрыты на всех входах; выбор ТВ доступен иконкой трансляции, отдельной кнопки подключения нет |
| A03 | ТВ сохранён, но offline или не выбран | Он виден в общем списке; CTA запуска не разблокированы |
| A04 | Подключение к разрешённому доступному ТВ | Имя адресата видно; только после подтверждения соединения появляется запуск |
| A05 | Два доступных и один offline ТВ плюс телефон | Контекстный выбор предлагает только поддерживаемые ТВ; offline недоступен; общий список не фильтруется навсегда |
| A06 | Запуск из карточки, истории, серии, файла, deep link | Каждый путь проверяет текущий адресат и полномочия; повторный тап не создаёт два запуска |
| A07 | Старт / подготовка / первый кадр | Статусы берутся с приёмника, успех не показан до его подтверждения; поток воспроизводится на ТВ |
| A08 | Тот же файл уже идёт на ТВ | Присоединение без перезапуска и сброса позиции |
| A09 | На ТВ другое видео | Подтверждение с именем ТВ и видео; отмена не меняет воспроизведение; устаревшая сессия перепроверяется |
| A10 | Выбрать другое устройство во время просмотра | Сам выбор не переносит и не запускает видео; прежний ТВ продолжает просмотр; команды имеют верную цель |
| A11 | Переименовать своё устройство обычным пользователем | Из ⋮ открывается компактный модальный диалог, не новая страница. Работает для ТВ/телефона/планшета, без admin; активная сессия не рвётся |
| A12 | Пустое/длинное имя, дубликат, сервер offline | Валидация 1–32 Unicode-символа; дубликат различим по ID; подтверждение синхронизации честное |
| A13 | Изменить чужое устройство / отозвать своё | Чужое запрещено API; отзыв немедленно убирает право подключения/запуска |
| A14 | Существующее сканирование и pairing | Экран, точки входа, QR/ввод кода и разрешения не изменены; новый экран добавления не создан |
| A15 | Системные play/pause/seek | Управляют текущим видео на конкретном ТВ и отражают изменения пультом; seek доступен лишь при поддержке |
| A16 | Громкость системными средствами | Меняется удалённая громкость при поддержке, не локальная громкость телефона; ограничения route не скрываются |
| A17 | Свернуть/заблокировать/пересоздать телефон | Видео продолжается на ТВ, доступна системная карточка в поддерживаемых условиях; нет дубликатов сессии |
| A18 | Второй телефон в LAN / запуск с пульта ТВ | Проверено появление и присоединение системного управления; условия Cast описаны фактически |
| A19 | Разрыв Wi-Fi, ТВ выключен, процесс завершён | Кнопка запуска скрыта, сообщение и «Повторить» появляются в карточке без отдельного экрана; нет выдуманного состояния паузы; TV не останавливается автоматически из-за потери контроллера; повтор читает актуальное состояние |
| A20 | Отключённые уведомления / несовместимый ТВ | Нет обещания обхода настроек; совместимость и причины отражены; самодельный пульт не появляется |
| A21 | Обход всех экранов телефона | Нет собственных кнопок pause/play/seek/volume для текущей ТВ-сессии и нет отдельного mini-player с транспортом |
| A22 | TalkBack, 200% fontScale, tablet, TV D-pad | Тип/статус доступны голосом, 48dp цели, CTA над IME, нет обрезания, Back возвращает фокус к исходному элементу |
| A23 | Самостоятельный просмотр на ТВ | Сохраняется работа физическим пультом; телевизор не требует подключения к самому себе |
| A24 | Закладка без ТВ / с ТВ / во время просмотра | Кнопка справа сверху доступна во всех состояниях; добавляет/удаляет фильм из «Моего», не выбирает ТВ и не запускает видео |
| A25 | Нажать отдельную иконку трансляции до/после подключения | Открывается «Где смотреть?»; выбор меняет адресат без запуска; Back/свайп сохраняет прежний выбор и возвращает фокус к иконке |
| A26 | Нажать «Смотреть на ТВ · Гостиная» при действующем соединении | Видео запускается на выбранном ТВ без повторного открытия выбора устройства; закладка и выбор ТВ не подменяют запуск |

Матрица устройства/версии и доказательства A15–A20 обязательны перед заявлением «как у Cast». Растровые макеты и unit tests этого не подтверждают.
