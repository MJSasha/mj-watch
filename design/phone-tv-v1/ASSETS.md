# Макеты: происхождение и проверка

Сгенерированы встроенным ImageGen 17.11.2026 как продолжение существующего интерфейса MJWatch. Источники визуального языка: `../spec/DESIGN-SYSTEM.md`, первоначальные `mobile-detail.jpg` и `tv-home.jpg`, теперь в `../archive/initial-v1/screens/`.

| Файл | Содержание | Ключевые требования промпта |
|---|---|---|
| 01-viewing-states.png | Карточка: нет ТВ / подключён / уже идёт | Сохранить исходную карточку; без запуска до подключения; имя адресата; без собственного транспорта |
| 02-unified-devices.png | Общие устройства / добавление / переименование | Один список всех типов, разные Material-иконки; QR/код; пользовательское имя 1–32 символа |
| 03-target-and-recovery.png | Контекстный выбор / замена видео / потеря связи | Несколько ТВ, offline, подтверждение занятого приёмника; нет рисованной системной панели Android |

Отклонённые ранние листы с отдельным меню ТВ и нарисованной Android-панелью не включены в поставку. Финальные листы просмотрены после генерации: подписи и состояние назначения читаются, собственного транспорта нет, общий список включает телефон и планшет. Это визуальная проверка растров, не runtime QA.

Ограничения: ImageGen-растр не является редактируемым Figma-файлом или pixel-perfect спецификацией. Размещение системных панелей не проектируется. Референсные размеры экранов и требования адаптации заданы в README; нативный UI должен поддерживать реальный viewport, доступность и IME. При расхождении текста изображения с документом приоритет у README и ACCEPTANCE.
