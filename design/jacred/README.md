# JacRed в MJWatch

[Макеты трёх разделов](mockups.html)

В прежней «Диагностике» карточки поиска, каталога и сбора находились в одном потоке. Настройки установки, расписания и трекеров открывались по SSH, как и встроенная веб-админка. Сбор MJWatch показывал результат запросов к трекерам. Прогресс фоновых операций JacRed доступен отдельно через `/health/background-jobs`.

На [публичной странице Jobs](https://jac.red/jobs) во время проверки отображалось пустое состояние с временем обновления и кнопкой ручного запроса. В [исходниках версии 3.20.0-oss](https://github.com/jacred-fdb/jacred/blob/3.20.0-oss/web/src/pages/JobsPage.vue) видны два вида активных операций, время запуска, длительность, обработанные страницы и текущая категория. Список описывает активные операции текущего процесса.

| Раздел | Содержание |
| --- | --- |
| Обзор | Доступность поиска, режим наполнения, статистика каталога и её отдельное обновление, разбивка по трекерам, проверка запроса. |
| Задачи | Прогресс активных операций с опросом каждые 15 секунд, ручное обновление снимка, подтверждение обновления раздач по трекеру, сбор и история MJWatch. |
| Настройки | SSH-доступ, установка или запуск службы, режим наполнения, интервал, трекеры и встроенная веб-админка. |

Для нового списка и запуска по трекеру нужен сервер MJWatch 0.1.19. Для ручного запуска доступен [ограниченный по объёму этап обновления раздач](https://github.com/jacred-fdb/jacred/blob/3.20.0-oss/docs/api-reference/cron.mdx), если трекер поддерживает эту операцию и включён в сбор. JacRed сообщает о занятости трекера и не предоставляет API отмены отдельной задачи.

При доработке использованы рекомендации [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) для мониторинга и Jetpack Compose. Время снимка находится рядом с обновлением, процент сопровождает счётчик страниц, а действия для свободных трекеров собраны в компактный список. Кнопки имеют видимый фокус, доступные имена и цели нажатия от 48 dp.

## Сверка

Проверяем одинаковый порядок данных в макете и нативной панели: время снимка, имя трекера, тип операции, счётчик страниц, полоса прогресса, текущая позиция и действия. Цвета и фокус берутся из темы MJWatch. Тест использует снимок с активным полным сбором и вторым трекером, доступным для запуска. Он проверяет сохранение снимка при ошибке связи, блокировку занятых и недоступных действий, отмену подтверждения и обновление списка после запуска.
