# MJWatch 0.4.1 — исправления по пользовательским скриншотам

2026-11-15. Снимки пользователя использованы для анализа и не добавляются в Git. Все изображения в этом отчёте и README получены на собственных AVD с fixtures.

## Исправлено

1. **Меню:** единые прямоугольники со скруглением 12dp на TV и планшете, filled-иконки по макету, разделитель rail, одинаковые состояния и позиция настроек снизу. В редакторах подключений выделяется раздел настроек.
2. **Подключения:** Jackett / JacRed, TorrServer и каталог — самостоятельные кнопки и отдельные страницы с соответствующими полями. Сохранение возвращает в настройки. AppBar Back и системный Back учитывают несохранённые изменения, IME закрывается первым системным Back. Чужие параметры и секреты сохраняются.
3. **Стиль:** качество, язык и субтитры используют одинаковые строки: отступы, белые заголовки и иконки, вторичный текст и chevron. Субтитры открывают выбор автоматического режима, выключения и языка; предпочтение применяется Media3.
4. **Длинное название:** управление и заголовок стоят последовательно. Короткая шапка без вымышленной обложки для raw-раздачи, до трёх строк заголовка; полное исходное имя доступно ниже. Нижний отступ измеряется по фактической высоте CTA.
5. **Обновления:** отдельная страница по образцу MJReader/MJAnime: установленная версия, статус, автопроверка и действия. Существующие загрузка/отмена/SHA256/package/certificate/установщик сохранены.
6. **Репозиторий:** SVG-баннер семейства MJ, badges, навигация README, свежие снимки телефона/планшета/TV, возможности, установка, сборка и документация. Соседние MJAnime/MJReader только читались.

## Проверено

- 27 core unit tests, debug/release обоих приложений и lint — pass.
- Phone API36 ARM64: стандартный suite 14 tests (6 passed, 8 opt-in/device checks skipped), включая mock HTTP, fake Media3 и две новые UI-регрессии.
- Новые UI-регрессии: отдельные адресные формы; сохранение без потери постороннего секрета; отмена несохранённого адреса через Back; субтитры и переход на обновления; отсутствие пересечения toolbar/title при очень длинной строке.
- Phone 360×800dp/fontScale 2.0: обе новые UI-регрессии pass.
- TV API36: D-pad flow, первый кадр, Back, прогресс и возврат фокуса — pass.
- Tablet API36 1200×800dp: split-pane test и visual fixture suite — pass.
- SVG-баннер проверен системным Quick Look; локальные ссылки и изображения README проверены.
