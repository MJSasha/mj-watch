# Офлайн-просмотр на телефоне и планшете

На эмуляторе Android 16 проверены обе фазы `scripts/check-offline-emulator.sh` при компактной и широкой компоновке мобильной APK. Тестовый HTTP-сервер отдавал три различных MP4 через протокол TorrServer. В интерфейсе выбраны фильм и две серии. Проверены точное совпадение скачанных байтов, отдельная запись каждой серии и отсутствие автоматического запуска при скачивании.

Затем тест остановил процесс приложения, включил авиарежим и отключил Wi-Fi и мобильные данные. После запуска приложения из «Моё → Загрузки» каждый файл открылся в Media3. Тест проверил локальный URI, первый кадр, продвижение позиции и отсутствие активной сети.

| Планшет | [Прогресс](tablet-downloading.png) | [Готовые файлы](tablet-ready.png) | [Плеер](tablet-player.png) |

Отдельная HTTPS-проверка managed воспроизвела истечение токена и смену идентификатора файла на сервере. Клиент обновил авторизацию, проверил хеш раздачи, путь и размер серии и продолжил передачу с сохранённого смещения. Проверка локального плеера с просроченной managed-сессией не зафиксировала запросов к серверу.

Собранные манифесты проверены через Android Build Tools. Служба загрузки и разрешение dataSync зарегистрированы только в мобильной APK. Семь проверок Android TV на эмуляторе охватили навигацию и обычный плеер, включая отсутствие действий скачивания. Физические устройства в этих прогонах не использовались.
