# Доступ к кнопкам раздач в MJ Watch 0.12.47

Проверено на Android 36 AVD при 1080×1920 и 1080×2340. Закреплённые кнопки «Смотреть» и «Скачать» полностью выше плавающей панели при системном отступе и при скрытой системной навигации.

- [Обе кнопки активны](download-enabled.png). Нажатие «Скачать» на вкладке раздач открыло выбор файлов. Тест подтвердил загрузку и совпадение полученных байтов.
- [Компактный телефон](compact.png) и [высокий телефон](tall.png) со скрытым системным индикатором. Нажатие «Смотреть» реально открыло экран выбора файлов. В этих двух кадрах использован деморежим с недоступной загрузкой.
- Проверки главной, прокрутки настроек, поворота, экрана выбора раздачи и возврата прошли. Обёртка плавающей панели используется на главной, поиске, в библиотеке и сведениях. У экранов выбора файлов, подключения и обновлений собственное системное размещение.
