# 0.9.12 — TV home UX

Release candidate based on `b2ff3f2` (0.9.11). Carries the approved TV home, compact focus/button geometry and inline TV/mobile player timelines. Server 0.1.8 and settings from 0.9.11 are retained.

The implementation was checked locally on an isolated API 36 Android TV emulator: 6 TV home/button UI tests, 2 repeated home scenarios, 21 player UI tests from the preceding layout work, playback unit tests, TV/mobile lint and builds. Subsequent caption fixes passed both home scenarios again.

Publication is gated by the repository Android workflow: server race/vet/packaging, Android unit/lint/debug+release builds, complete phone and TV runtime tests, and playback tests on TV. Signed APKs, the update manifest, server supply and SHA256SUMS are generated by the existing publish job.

No physical television/OEM acceptance is claimed. The mobile home keeps its existing layout.
