# Загрузки и выбор устройства

Сравнение исходного debug APK 0.10.0 и сборки ветки `codex/offline-design-review`. Обе сборки сняты на Android 16 API 36 при одинаковых настройках экрана. Телефон 1080 × 1920 при 420 dpi, планшет 1920 × 1200 при 280 dpi.

| Шаг | Наблюдение | Телефон | Планшет |
| --- | --- | --- | --- |
| 1. Раздача без подключённого ТВ | «Смотреть» открывает локальное воспроизведение. На телефоне и планшете «Смотреть» и «Скачать» стоят рядом. Качество 720p указано на самой раздаче. | [До](before-phone-01-actions-without-tv.png) · [После](after-phone-01-actions-without-tv.png) | [До](before-tablet-01-actions-without-tv.png) · [После](after-tablet-01-actions-without-tv.png) |
| 2. Раздача с подключённым ТВ и неизвестным качеством | Кнопки сохраняют подписи «Смотреть» и «Скачать». В карточке остаются название и источник. Фильтр «Не указано» доступен в расширенных фильтрах. | [До](before-phone-02-unknown-quality-with-tv.png) · [После](after-phone-02-unknown-quality-with-tv.png) | [До](before-tablet-02-unknown-quality-with-tv.png) · [После](after-tablet-02-unknown-quality-with-tv.png) |
| 3. Адресат просмотра | По «Смотреть» открывается меню «На этом устройстве» и «На ТВ · Гостиная». Первый пункт запустил Media3 на телефоне, второй передал выбранный файл тестовому ТВ через сервер. | [Меню](after-phone-03-playback-destination.png) | [Меню](after-tablet-03-playback-destination.png) |
| 4. «Моё» → «Загрузки» | После скачивания сохраняются шапка «Моё» и остальные вкладки. «Загрузки» отмечены как выбранная вкладка. После переключения на «Буду смотреть» и обратно готовый файл остаётся на месте. | [До](before-phone-04-ready-downloads.png) · [После](after-phone-04-ready-downloads.png) | [До](before-tablet-04-ready-downloads.png) · [После](after-tablet-04-ready-downloads.png) |

На телефоне при 420 dpi округление ширины переносило «Скачать» на следующую строку. После исправления тест проверяет одинаковую верхнюю координату обеих кнопок на телефоне и планшете. Край вкладки «История» на телефоне виден частично, строка вкладок прокручивается горизонтально. [Действия](after-phone-01-actions-without-tv.png) · [Вкладки](after-phone-04-ready-downloads.png)

При подключённом ТВ «Скачать» записывает файл локально и оставляет соединение активным. Тест сравнил файл с исходным MP4 байт в байт и подтвердил отсутствие команды загрузки на ТВ.

Обе основные кнопки имеют высоту области нажатия не менее 48 dp. Тест подтвердил семантику выбранной вкладки. Проверка использовала реальный сервер MJWatch и тестовый приёмник протокола ТВ. Фактическое декодирование проверено в мобильном Media3. Доступность проверена в пределах размеров кнопок и семантики вкладки при стандартном размере шрифта.

На финальной сборке прошли обе проверки обычного маршрута и обе фазы офлайн-регрессии. Фильм и две отдельные серии скачались и воспроизвелись после принудительной остановки приложения в авиарежиме. Проверка с просроченной managed-сессией также прошла.

Тест сравнения запускается классом [OfflineDesignReviewTest](../../../app-mobile/src/androidTest/java/dev/mjwatch/mobile/OfflineDesignReviewTest.kt) с аргументом `isolatedDesignReview=true` на локальной [серверной фикстуре](../../../server/cmd/fixture/main.go). Для регрессии холодного офлайн-старта используется [check-offline-emulator.sh](../../../scripts/check-offline-emulator.sh).
