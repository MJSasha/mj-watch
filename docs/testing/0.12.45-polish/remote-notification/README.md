# Пауза и воспроизведение TV из уведомления телефона

Проверены копии официальных APK MJ Watch 0.12.45 (код 1283), переподписанные тестовым ключом для Android Instrumentation, и debug-сборка пакета 0.12.46 с той же реализацией транспорта. Телефон и Android TV — два AVD с Android 36 и один локальный HTTPS-стенд. Физический TV в проверке не участвовал.

Тест отправляет видео на TV через интерфейс приложения, убирает телефонное приложение в фон и нажимает системные кнопки в шторке. Статус приходит с TV через сервер. Пауза оставляет реальную позицию ExoPlayer неизменной в двух замерах, после «Воспроизвести» позиция продолжает расти. В шторке меняется системная кнопка. Также проверены прямые действия уведомления для старого способа управления и локальные клавиши TV. Полный тест на 0.12.45 прошёл. Debug-сборка пакета с прежним транспортом прошла сценарий системной шторки. Сбой пользователя на стенде не воспроизвёлся. В выпуске остаётся регрессионное покрытие.
