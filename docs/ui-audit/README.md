`Похожие` использует элементы того же раздела уже загруженного каталога. Это локальная подборка, не ответ TMDB recommendations. Без данных показано пустое состояние. Из макетов не копируются вымышленные рейтинги, длительности, имена эпизодов, скорости сети, число пиров или успешные проверки.

## Что проверяется скриншотами

- `before/`: снимки исходного приложения до правок; отдельно raw demo и синтетический каталог.
- `after/`: оригинальные AVD PNG после правок. Все названия/постеры каталога в visual suite — fixtures; видео — локальный MP4.
- Галерея сохраняет исходные пропорции изображений. Различия данных и системных status/navigation bars не считаются ошибками верстки.
- Для TV сохранена штатная плотность AVD (213 dpi); размеры тач/focus-контролов не уменьшались ради буквального совпадения с JPG.
- `AuditScreensTest` запускается только с `-e audit true`. Ошибка подключения воспроизводится через закрытый localhost port 1 эмулятора, без пользовательских серверов.

Системная подсказка fullscreen при первом запуске учитывается в тестах отдельно (включая регистр текста Android 8). В visual suite Compose clock продвигается перед снимками, чтобы успевали обновиться UI и асинхронные постеры.

Не подтверждались в этой итерации: live JacRed/TorrServer, физический телевизор/проектор, полная TalkBack/switch-access матрица и производительность по profiler. Скриншоты не используются как доказательство этих свойств. Реальные сетевые/track/codec ограничения из прежних отчётов сохраняются. HTML-галерея служит отчётом и не входит в APK.
