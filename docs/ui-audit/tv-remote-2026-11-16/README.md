# Аудит Android TV: управление с пульта

Дата: 16 ноября 2026. Итог: основной путь до локального видео проходим с D-pad/OK/Back, но есть три приоритетные проблемы: выход фокуса со шкалы времени, видимость фокуса основных кнопок и читаемость главной в светлой теме.

## Условия и границы

- Установлен локальный `app-tv-debug.apk`, `dev.mjwatch.tv`, версия 0.6.2 / 14. SHA-256: `508ed4c8c211c12c77b9cd68314d71420251fe28701958ff4395943234c5f2e8`.
- Отдельный эмулятор `mjwatch-issues-6-7`, API 36 arm64, 1920×1080, 240 dpi. Это телефонный Android image с TV-оболочкой приложения, **не физический Android TV**. Системные панели и телефонная клавиатура на снимках относятся к этому окружению.
- Захват: ADB `screencap`; управление: события D-pad, OK, Back. Все приведённые PNG сняты в этом запуске, сохранены и просмотрены. Мышь для прохождения сценариев не использовалась.
- Первая часть — сохранённое тестовое managed-состояние с локальными демонстрационными данными. Затем существующий `VerticalFlowTest` подготовил direct/demo-состояние; тест завершился `OK (1 test)`. Его программная установка фокуса **не считается доказательством D-pad-навигации**: после него основной путь был пройден отдельно кнопками пульта.
- Исходный код не изменялся в рамках аудита. Выводы относятся к указанному APK, а не к параллельно меняющимся исходникам или будущему QR-сценарию.
- Не проверены реальный TorrServer/каталог, полноценный managed-вход, импорт файла на физическом ТВ, аппаратное декодирование, голосовой поиск, TalkBack, удержание кнопок и читабельность с дивана. Экранная клавиатура телефона не позволяет принять ввод за проверенный TV-сценарий. Полное соответствие требованиям доступности не заявляется.

## Приоритетные находки

### F1 · P1 · Фокус застревает на шкале времени

Шаг 9, снимок 23 и `timeline-focus.xml`. Во время паузы перейти с нижних кнопок вверх на шкалу. Повторное ↑ не переводит фокус на верхние кнопки. После ↓, →, OK фокус также остался на шкале; XML подтверждает `focused=true` у узла `[27,870][1893,894]`. В этом проходе вернуться к кнопкам стрелками не удалось, Back выходит из плеера.

**Исправление:** определить отдельное поведение навигации и изменения позиции: ←/→ перематывают, ↑/↓ выводят фокус к верхнему/нижнему ряду. Проверить на длинном видео, что стрелки не меняют позицию неожиданно.

**Приёмка:** с паузы ↑ на шкалу, ↓ обратно к кнопке воспроизведения; ↑ со шкалы к верхнему ряду; цикл повторяется без выхода из плеера.

### F2 · P1 · Состояние фокуса основных кнопок почти не различается

Шаги 1, 2 и 8: у «О фильме», «Выбрать раздачу», «Смотреть» нет столь же заметной рамки, как у карточек. Особенно показательная пара 16 → 17: рамка файла исчезает после →, а кнопка «Смотреть» визуально практически та же. Следующий OK запускает видео, то есть кнопка получила фокус.

**Исправление:** одинаково заметный контрастный контур с зазором для всех основных кнопок; отличать постоянный акцент действия, выбранное состояние и текущий фокус.

**Приёмка:** фокус однозначно виден на каждой кнопке в тёмной и светлой теме, без необходимости нажимать OK для проверки. Это риск доступности для пользователей со сниженным зрением.

### F3 · P1 · Главная в светлой теме теряет текст на изображении

Шаг 7, снимок 14. В системной светлой теме тёмные название «Тихая орбита», вкладки, подпись и заголовок «Тестовые раздачи» лежат поверх тёмной подложки изображения и плохо читаются. На экране деталей светлый текст на аналогичной подложке читается существенно лучше (шаг 9, снимок 20).

**Исправление:** отдельные цвета текста и фокуса для области изображения, независимо от общей темы; либо светлая подложка в светлой теме. Контраст после исправления нужно измерить, а затем проверить на ТВ с расстояния.

### F4 · P2 · При переходах фокус оказывается вне содержимого нового экрана

Шаг 4: после открытия ошибки фокус на верхней кнопке «Назад», а не на варианте восстановления. Шаг 6: после выбора «Способ подключения» фокус оказывается на иконке главной в общем меню (11); после открытия формы — опять на верхнем «Назад» (12). Содержимое уже сменилось, но немедленный OK не продолжает выбранную задачу.

**Исправление:** задавать начальный фокус на первом полезном действии нового экрана; на ошибке выбирать осмысленное восстановление. При возврате восстанавливать прежний элемент и прокрутку.

**Приёмка:** открытие способа подключения фокусирует первый вариант, форма — первое поле, ошибка — применимое действие восстановления. Проверить повторное открытие и Back.

### F5 · P2 · Иконки общего меню не получают видимых подписей

Шаги 1, 5 и 10: даже при фокусе остаются только иконки. Для нового пользователя «История» и «Моё» требуют расшифровки. В дереве UI есть названия, но зрячий пользователь с пультом их не видит.

**Исправление:** показывать название раздела рядом с активной иконкой или раскрывать меню при входе фокуса. Сохранить имеющиеся семантические подписи.

### F6 · P2 · Выбор файла требует отдельного перехода к запуску

Шаг 8, снимки 15–17: OK выбирает файл, фокус остаётся в списке, затем требуется → к правой панели и ещё OK. Путь работает, но ожидаемый результат OK на названии серии неочевиден; повторный OK на выбранном файле не является быстрым запуском.

**Исправление:** сохранить явный выбор для сложных раздач, но добавить понятное действие «OK — смотреть» на уже выбранном файле либо перенести фокус к «Смотреть» после выбора. Поведение должно быть одинаковым для всех серий.

### F7 · P3 · В дорожках показан технический язык `und`

Шаг 9, снимок 24: «Аудио: und ✓». В тестовом видео язык не указан; это не ошибка определения русского/английского, но техническое значение пользователю непонятно.

**Исправление:** «Аудио: язык не указан», при наличии метаданных — понятные название, язык и формат. Проверку нескольких реальных дорожек выполнить отдельно.

## Очерёдность исправлений и проверки

1. F1: выход со шкалы времени стрелками; затем F2: единый видимый фокус всех действий.
2. F3: читаемость области изображения в обеих темах.
3. F4–F6: начальный фокус, подписи меню и сокращение запуска серии.
4. F7: понятные названия дорожек.
5. Повторить сценарий на Android TV/Google TV с штатной клавиатурой и физическим пультом: поиск → длинный список → фильм → серия → пауза → перемотка → дорожки → Back; отдельно проверить ввод URL/кода, удержание стрелок, восстановление прокрутки и крупный шрифт.

Ранее открытые #8 (нет «Сериалы») и #9 (вкладки «Аниме»/«Мультфильмы») не переобъявлялись подтверждёнными дефектами этого аудита: реальный каталог в текущем проходе не проверялся. Проверка управления пользователями из #10 также вне пройденного сценария.
