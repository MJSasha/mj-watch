# Дизайн семейства MJ

Основной вход для просмотра — [иллюстрированное руководство](guide.html). Его можно открыть обычным браузером без сервера: все изображения, шрифты и стили встроены в HTML. Ссылки на исходники и JSON требуют соседних файлов; содержание самого руководства доступно автономно.

## Файлы

- [Нормативный текст](../MJ-FAMILY-DESIGN.md): 18 разделов, 63 именованных правила, спецификации 15 компонентов, сценарии, исключения и приёмка.
- [guide.html](guide.html): цветовые образцы, варианты launcher, состояния controls, изображения трёх приложений; переключение темы учебных образцов и увеличение screenshots.
- [tokens.json](tokens.json): целевые значения цветов, типографики, размеров, focus, motion и layout.
- [contrast.json](contrast.json): автоматически рассчитанные 16 пар foreground/background и пороги.
- [RESEARCH.md](RESEARCH.md): первоначальный сравнительный разбор и ссылки на источники; не второй стандарт.
- [assets/PROVENANCE.md](assets/PROVENANCE.md): происхождение ресурсов и лицензия Roboto.

## Обновление

Изменить нормативный текст и соответствующие значения tokens.json, затем пересобрать HTML. Числа в учебных образцах должны оставаться согласованными с tokens.json. Не объявлять приложения соответствующими стандарту до предметной приёмки.

Генератор использует Node.js и пакет marked. Можно использовать уже доступный marked; устанавливать зависимости в сами приложения не требуется.

```sh
MJ_MARKED_MODULE=/absolute/path/to/marked/lib/marked.esm.js node docs/mj-family/build-guide.mjs
```

Если marked доступен обычному Node resolution, переменная не требуется. При работе из Codex пути bundled Node/marked предоставляет workspace dependency loader. Команду выполнять из корня MJWatch.

Генератор проверяет заданные контрастные пары, собирает содержание/указатель и встраивает ресурсы. Полученный guide.html хранится как готовый переносимый документ, поэтому его можно использовать без сборочного окружения.

Печать / PDF открывает стандартное окно браузера. Печатное оформление включено в HTML; отдельный проверенный PDF в комплект не входит.
